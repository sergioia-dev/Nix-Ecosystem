# NixOS Configuration

## Architecture

```
nixos/
├── common/           # Shared across all hosts
│   ├── base.nix      # Common system settings (locale, users, Nix, pipewire, etc.)
│   └── hardware/     # Per-machine hardware configs (generated by nixos-generate-config)
│       ├── personal-laptop.nix
│       └── work-laptop.nix
├── host/             # Per-host entry points
│   ├── personal-laptop/configuration.nix   # Thin: imports base + hardware
│   └── work-laptop/configuration.nix       # Thin: imports base + hardware
└── module/           # Reusable NixOS modules organized by concern
    ├── moduleBundle.nix
    ├── system/       (desktop, shell, profile)
    ├── database/     (mysql, postgresql, sqlite)
    └── tool/         (docker, nginx, openssh, etc.)
```

## How it works

- **`common/base.nix`** contains all settings shared by every host: user accounts, locale,
  timezone, Nix daemon configuration, bootloader, pipewire, networking, etc.
- **`common/hardware/*.nix`** are the per-machine hardware configurations generated by
  `nixos-generate-config`. They are symlinked from each host directory so that
  regeneration transparently updates them.
- **`host/<name>/configuration.nix`** is the entry point referenced from `flake.nix`.
  It imports `common/base.nix` + the relevant hardware config. Any host-specific
  overrides go here (e.g. different hostname, timezone, or additional services).
- **`module/`** provides opt-in feature bundles (system, database, tool) that are
  imported by `common/base.nix`. Each module uses enable-options like
  `tool.docker.enable`, `system.desktop.gnome.enable`, etc.

## Adding a new host

1. Run `nixos-generate-config --root /mnt` to produce a `hardware-configuration.nix`.
2. Copy it to `nixos/common/hardware/<new-host>.nix`.
3. Create `nixos/host/<new-host>/configuration.nix`:

   ```nix
   { inputs, ... }: {
     imports = [
       ../../common/base.nix
       ../../common/hardware/<new-host>.nix
     ];
   }
   ```

4. Add a new `nixosConfigurations.<name>` entry in `flake.nix` pointing to your
   new `configuration.nix`.

## Module options

All modules are opt-in via boolean enable options. See each module file for the
specific option name. The top-level option groups are:

- `system.desktop.*`    — desktop environment (gnome, kdePlasma, cosmic)
- `system.shell.*`     — shell (zsh)
- `system.profile.*`   — power/performance profiles
- `database.*`         — database services (mysql, postgresql, sqlite)
- `tool.*`             — miscellaneous tools (docker, nginx, openssh, steam, etc.)
